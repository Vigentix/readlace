# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's
**Report a vulnerability** button on the repository's Security tab (private
vulnerability reporting) and include:

- what is affected and how to reproduce it;
- the impact you expect;
- the Readlace version and browser.

We aim to acknowledge reports within a few working days and will credit you in
the fix unless you prefer otherwise.

## Scope

In scope: the extension in this repository, including how it stores and uses
the user's provider API key, the messages between its contexts, and the content
it injects into pages.

Out of scope: vulnerabilities in third-party providers (OpenAI, Google) or in
the browser itself; reports that require a compromised device or browser
profile.
